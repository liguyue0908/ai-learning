第 2 课：Claude Code 能力全景 (1/3)

了解你手上的"AI 瑞士军刀"——它远不止聊天

🖥️ 一、Claude Code 不是"聊天机器人"

大多数人第一次用 Claude Code，会觉得"这就是个聊天窗口"。这是最大的误解。

Claude Code 是一个完整的 AI 工作台，它的能力分为四个层级：

层级能力你能让它做什么
L1 对话问答、分析、写作、头脑风暴讨论方案、分析问题、生成文案
L2 文件读取、创建、编辑本地文件读你的 Excel 数据、帮你写报告并保存
L3 命令运行终端命令、安装程序批量处理文件、运行数据分析脚本
L4 编排Agent 子代理、Workflow 流水线同时分析 5 个渠道数据，自动汇总
普通 ChatGPT：只有 L1。 Claude Code：L1-L4 全覆盖。

这意味着你不是在和一个"聊天 AI"对话，而是在指挥一个能实际操控你电脑的 AI 助手。

🔑 二、理解"工具调用"：AI 的"手"

L2-L4 的能力来自一个关键机制：工具调用（Tool Use）。

传统 AI 对话：你问 → AI 回答（纯文本）

Claude Code：你问 → AI 判断"我需要读取文件" → 调用读文件工具 → 读取内容 → 分析 → 回复你

AI 不只是"说"，它真的"做"了。 你会在对话中看到类似这样的提示：
Read(file_path='Q3服务数据.xlsx') Write(file_path='分析报告.md', content='...')

这些不是给你看的——这是 AI 在"动手"。每次工具调用，AI 都实际执行了操作。你的数据文件真的被读取了，报告文件真的被创建了。

⚡ 三、最重要的交互技巧：@ 引用和拖拽

Claude Code 有两个文件交互的"快速通道"：

方式 1：@ 符号引用

在对话中输入 @ 然后输入文件名，AI 会自动定位到你的文件。比手写路径快 10 倍，而且不会出错。

请分析 @Q3服务工单.xlsx 中的投诉趋势
方式 2：直接拖拽

把文件拖进 Claude Code 窗口（桌面版），自动创建引用。

第 2 课：Claude Code 能力全景 (2/3)

🎯 四、你的五个工作场景 × Claude Code 能力

这是今天最重要的部分——把你每天的工作，映射到 AI 能力上。

场景 1：客户服务运营

- L1 对话：分析服务流程的薄弱环节，讨论改善方案

- L2 文件：读取服务工单 Excel，自动分类投诉类型

- L3 命令：批量重命名/整理服务文档

- 典型用法：读取 @本月工单.xlsx，按投诉类型分类，统计 Top5 问题

场景 2：渠道建设运营

- L1 对话：讨论渠道分层策略，头脑风暴赋能方案

- L2 文件：读取渠道 KPI 数据，生成多维度对比表

- L4 编排：同时分析 10 个渠道数据，自动汇总差异

- 典型用法：分析 @渠道Q3数据.csv，按能力和意愿两个维度对渠道分层

场景 3：项目管理

- L1 对话：讨论项目风险点，设计 SOP 节点

- L2 文件：基于项目需求自动生成 SOP 文档

- L3 命令：创建项目文件夹结构，初始化文档模板

- 典型用法：为 XX 项目设计 SOP 流程框架，生成 markdown 文档

场景 4：售后运营（ITR）

- L1 对话：诊断 ITR 流程断点，分析闭环率

- L2 文件：读取售后数据，生成可视化分析

- L4 编排：多维度交叉分析（时效×区域×人员）

- 典型用法：读取 @售后数据.xlsx，分析各环节处理时长，找出瓶颈

场景 5：组织建设

- L1 对话：讨论人才梯队方案，组织健康度诊断

- L2 文件：读取人员能力评估表，生成九宫格分析

- L3 命令：批量生成培训材料

- 典型用法：基于 @能力评估.xlsx 做人才九宫格分析

🛡️ 五、安全边界：Permission 系统

Claude Code 在执行 L2-L4 操作前会弹窗请求你的许可：

- 🟢 纯对话 → 不需要许可

- 🟡 读取文件 → 需要你确认

- 🟠 创建/修改文件 → 需要你确认

- 🔴 运行命令/网络请求 → 需要你确认

原则：看清楚再确认，不确定就拒绝。 AI 是你的工具，最终控制权永远在你手里。

🧪 六、常见错误与纠正

错误 1：「AI 帮你做完你就信了」

❌ 让 AI 分析数据后直接拿结论去汇报

✅ 让 AI 展示分析过程，你验证关键数据点后再用

错误 2：「只说一次，说不清楚就算了」

❌ "帮我做个渠道分析" → AI 输出很泛 → "AI 不好用"

✅ "帮我做渠道分析，关注转化率和客单价两个指标，按区域对比，用表格输出" → AI 输出精准

错误 3：「一个对话聊所有事」

❌ 在一个对话里聊服务运营、又聊项目、又聊组织建设

✅ 一个大型主题开一个新对话，保持上下文聚焦

错误 4：「害怕让 AI 操作文件」

❌ 永远只用对话功能，所有文件操作自己来

✅ 先从小操作开始（读取文件、生成报告），逐步建立信任
