## 第 5 课：AI 的"手"——读析写工作流 (1/3)

> 今天你会掌握 Claude Code 最高频的使用模式，80% 的工作都能套这个流程

---

### 🔄 一、"读-析-写"三步工作流

这是 Claude Code 最核心的工作模式。把 AI 从"聊天工具"变成"生产力引擎"：

```
📥 读取 READ   → 让 AI 看见你的数据
🔍 分析 ANALYZE → 让 AI 理解并挖掘洞察
📝 生成 WRITE   → 让 AI 产出可交付的成果
```

**传统方式 vs AI 方式——同一个任务：**

| 环节 | 传统方式 | AI 方式 |
|------|---------|--------|
| 读取 | 手动打开 Excel，筛选，排序 | "读取 @数据.xlsx" |
| 分析 | 自己做透视表，画图，找规律 | "按 3 个维度分析趋势和异常" |
| 生成 | 打开 Word/PPT，排版，写结论 | "生成报告，保存为 .md 文件" |
| **总耗时** | **60-90 分钟** | **5-10 分钟 + 你审核微调** |

---

### 📊 二、实战拆解：一份售后服务月报的诞生

**场景：** 你有本月 500 条服务工单数据，需要写月报向上级汇报。

**Step 1：读取**
> "读取桌面上的 '8月服务工单.xlsx'，先告诉我这份数据的基本结构：有哪些列、共多少条记录、数据有没有明显缺失。"

AI 读取文件后告诉你：12 列，498 条，完成时间列有 23 条缺失。

**你获得的价值：** 不用打开 Excel 就知道数据全貌和数据质量问题。

**Step 2：分析**
> "基于这份数据，分析以下维度：
> 1) 工单量日趋势（有没有异常高峰日）
> 2) 处理时长分布（均值/中位数/超过 48h 的工单占比）
> 3) 投诉类型 Top 5
> 4) 按区域对比（哪个区域处理时长最长）
> 每个维度给出关键发现和数据支撑。"

AI 逐维度给出分析，附带具体数字。

**你获得的价值：** 别人花 40 分钟做的分析，你 2 分钟拿到初版。

**Step 3：生成**
> "把以上分析整理成月报，保存为 markdown 文件。结构：1)核心摘要（3 句话）2)关键指标仪表盘 3)问题分析 4)改善建议（按优先级排列）。语气正式，适合向上汇报。"

AI 生成完整的 .md 文件。

**你获得的价值：** 可交付的初稿。你只需要审核数据准确性、调整措辞、补充你的业务判断。

### ⚡ 三、进阶技巧：让 AI 帮你"审"

读-析-写之后，还有关键一步：**审**。这是高手和新手的区别。

```
📥 读取 → 🔍 分析 → 📝 生成 → ✅ 审核
```

**审什么？**
- 逻辑一致性："检查报告中的数据和结论是否一致，有没有自相矛盾的地方"
- 完整性："有没有遗漏重要维度？哪些地方需要更多数据支撑？"
- 落地性："改善建议是否具体可执行？哪些建议需要更多前置条件？"
- 受众适配："这份报告是给总监看的，语言是否够精炼？是否突出了他关心的指标？"

**实战示例：**
> "用总监的视角审视这份报告。他最关心的是：1)问题有没有被控制住 2)团队在不在改善轨道上 3)需要他做什么决策。请据此调整报告的侧重点。"

---

### 🛡️ 四、安全与信任：Permission 系统详解

Claude Code 在执行操作前会弹窗请求你的许可。理解这个机制，你就能放心让 AI "动手"：

| 权限级别 | 触发场景 | 建议策略 |
|----------|---------|---------|
| 🟢 无需确认 | 纯对话、分析 | 随意使用 |
| 🟡 读取文件 | Read 工具 | 通常安全，直接允许 |
| 🟠 创建/修改文件 | Write、Edit | 看清楚文件名和路径再确认 |
| 🔴 执行命令 | Bash | 理解命令作用再允许，不确定就拒绝 |
| 🔴 网络请求 | WebFetch、API 调用 | 确认不会泄露敏感数据 |

**三条安全铁律：**
1. **不清楚的命令不执行。** 如果 AI 给出的 bash 命令你看不懂，先问"这个命令是做什么的？"
2. **敏感数据要脱敏。** 让 AI 分析数据前，确认文件中没有身份证号、手机号等隐私信息
3. **重要文件先备份。** 让 AI 大规模修改文件前，自己先做个备份

### 🎯 五、五个工作场景的读析写模板

**场景 1：客户服务运营**
```
读：读取 @本月工单.xlsx
析：工单量趋势、处理时长分布、投诉分类、区域差异
写：服务运营月报 + 3 条改善建议
```

**场景 2：渠道建设运营**
```
读：读取 @渠道Q3数据.csv
析：各渠道转化率/客单价对比、高潜力渠道识别、低效渠道诊断
写：渠道分层方案 + 差异化赋能策略
```

**场景 3：项目管理**
```
读：读取 @项目进度表.xlsx
析：延期任务分析、资源冲突识别、风险概率评估
写：项目健康度报告 + 风险应对方案
```

**场景 4：售后运营（ITR）**
```
读：读取 @ITR流程数据.xlsx
析：各环节处理时长、断点分析、闭环率趋势
写：ITR 流程诊断 + 优化路线图
```

**场景 5：组织建设**
```
读：读取 @能力评估.xlsx
析：人才九宫格、梯队健康度、关键岗位风险
写：人才盘点报告 + 梯队建设建议
```

### 🏋️ 今日练习（到公司后 10 分钟）

**完成任务：你的第一个完整"读析写"循环**

```
1. 找一份你本周真实需要分析的工作数据（Excel/CSV/文档）

2. 读取与分析：
   "读取 @[文件]，分析核心指标，找出 3 个最值得关注的数据发现"

3. 生成成果：
   "把分析结果整理成一份简报，保存为 [文件名]-简报.md"

4. 审核优化：
   "这份简报是给 [某位领导/同事] 看的，他的关注重点是 [X]，
   请调整侧重点，并检查数据逻辑是否一致"
```
