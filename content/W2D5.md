### 🗺️ 二、实战路线图

**场景设定：** 你是客服运营负责人，需要做本月服务质量全景分析。

**完整流程（分 3 个阶段）：**

**阶段 1：数据全景扫描（对话 1-3 轮）**
- 读取数据 → 检查数据质量 → 描述整体画像

**阶段 2：深度分析（对话 4-8 轮）**
- 投诉分类 → 趋势对比 → 根因分析 → 区域差异

**阶段 3：报告生成（对话 9-10 轮）**
- 综合结论 → 生成报告 → 保存文件

### 📋 三、Prompt 模板包（直接复制使用）

**模板 1：数据全景扫描**
```
你是客服数据运营专家。读取 @[你的数据文件]。
第1步：描述数据基本情况（记录数、字段、时间范围）

第3步：给出数据全景画像（5 个关键数字）
```

**模板 2：多维度对比**
```
基于以上数据，用表格对比：
| 维度 | 本月 | 上月 | 环比变化 | 是否异常 |
分析维度：工单量、处理时长、满意度、一次性解决率
异常标准：变化超过 20% 或连续 3 个月同一方向
```

### 📋 三、Prompt 模板包（续）

**模板 3：根因分析（思维链）**
```
针对 [最严重的问题]，分 5 步做根因分析：
第1步：列出所有可能的原因（不少于5个）
第2步：用排除法逐一判断，说明排除理由
第3步：对剩余原因做影响力评分（1-10）
第4步：给出 Top 3 根因
第5步：每个根因给出 1 条可直接执行的改善措施
```

**模板 4：三角色交叉验证**
```
请分别以三个角色审视以上分析结论：
角色A - 客服主管：这个分析漏了什么执行层的问题？
角色B - 客户：哪个问题最影响体验？
角色C - 运营总监：哪个问题最影响成本和效率？
综合三个角色的反馈，修正分析结论。
```

**模板 5：生成决策报告**
```
基于以上全部分析，生成一份决策报告，保存为 .md 文件。
结构：
一、核心摘要（3 句话，总监 30 秒能看懂）
二、关键指标仪表盘（5 个核心指标的表格）
三、问题分析（Top 3 问题，每个附数据和根因）
四、改善建议（按优先级排序，每条含：动作、负责人、预期效果、跟踪指标）
五、下月重点关注（3 个预警信号）
```
